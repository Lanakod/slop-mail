# Security policy

## Reporting a vulnerability

Reports are welcome in English or Russian. Use **Report a vulnerability** in the repository’s Security tab when available. If the button is missing, open an issue asking for a private contact and keep the technical details private. [Security tab](https://github.com/Lanakod/slop-mail/security) · [Issues](https://github.com/Lanakod/slop-mail/issues)

Include the Slop Mail version, operating system, affected feature and observed impact. For issues involving email rendering or account connections, use a synthetic message or test account. Remove mailbox credentials, tokens, personal correspondence and signing keys from any attachments.

## Updates

The latest desktop release and its signed updater packages are published on GitHub Releases. The client can also check for updates in Settings. [Latest release](https://github.com/Lanakod/slop-mail/releases/latest)

Dependabot checks the Rust, npm and GitHub Actions dependencies weekly and opens pull requests for available version updates. [Dependabot configuration](.github/dependabot.yml)
